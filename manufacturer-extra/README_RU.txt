Дополнительные исходные пакеты производителя

Здесь сохранены три пакета из исходной папки производителя для справки.
Мастер JetPack 7.2 НЕ устанавливает и НЕ запускает эти файлы.

- kernel-dtb ... jp6.0.0: пакет для другой версии JetPack; не устанавливать поверх JP7.2.
- kernel-dtb ... nx-jp4.4: пакет для другой платы/версии; не устанавливать на этот GEACX1 JP7.2.
- firmware-cpld ... sc-v1.2: пакет для отдельной модели GEACX1SC. Он не подходит
  как автоматическая замена CPLD обычного GEACX1 и не входит в восстановление
  Jetson/QSPI.

Большой DEB сохранён частями для ограничений GitHub. Корневой START.sh автоматически
собирает исходные файлы в ~/geacx1-kit-v1.3/manufacturer-extra/ и проверяет SHA-256.
Ничего из этой папки не запускается и не устанавливается.

Проверка сайтов производителя от 2 октября 2026 года также показала:

- заводской rootfs v1.01 размером 16,67 ГБ найден отдельно, но не проверен и сюда
  не включён; комплект использует NVIDIA Sample Root Filesystem R39.2.0 вместе с
  BSP, board, kernel и сервисами производителя;
- универсальный установщик не имеет доступной GEACX1-JP7.2.json (HTTP 404);
- архив с пометкой MCU для старого JP5.1.1 содержит тест GPIO/SPI, а не прошивку;
- старые CPLD v1.1/v1.3 и локальный rb v1.4 нельзя считать взаимозаменяемыми только
  по номеру версии. CPLD автоматически не прошивается.

GEACX1 Recovery

JetPack 7.2 • AGX Orin 32 ГБ • Ubuntu 24.04

Короткий маршрут

Публичный проект GitHub → Code → Download ZIP → распаковать проект → открыть корень проекта в терминале → bash START.sh → пункт 1.

Что понадобится

  • Ubuntu 24.04 LTS на Intel/AMD, диск ext4.
  • После распаковки комплекта на ext4 должно оставаться ≥80 ГиБ для подготовки; желательно 100–120 ГиБ для одного накопителя, около 180 ГиБ для обоих.
  • Интернет для инструментов Ubuntu через APT, питание платы, USB-A ↔ Micro-USB кабель данных без хаба.
  • GEACX1 / 510JX0 r3.0 / AGX Orin 32 GB P3701-0004.
32 ГБ — оперативная память, не размер накопителя.

Старая Ubuntu и SSH не нужны. Запись начинается только после Recovery и точной фразы подтверждения.

2. Распаковать и запустить

Распакуйте ZIP проекта
Правая кнопка → «Извлечь сюда».
Откройте корень проекта
Папка с START.sh, assemble.py, parts.json и payload/ → «Открыть в терминале».
Запустите подготовку комплектаbash START.sh

Что делает START.sh

  • читает parts.json и находит части в payload/;
  • проверяет контрольные суммы, собирает и распаковывает архив;
  • запускает оригинальный мастер;
  • создаёт новый ~/geacx1-kit-v1.4 и ничего не перезаписывает.
При ошибке проверки заново скачайте весь проект через Code → Download ZIP.

Повторный запуск

Для v1.4 заново скачайте проект и запустите корневой START.sh. Старую рабочую папку ~/geacx1-kit-v1.2 не используйте для новой прошивки.

3. Выбрать восстановление

Главное меню → 1 — восстановление с нуля.

ВыборЧто записывается
eMMCQSPI + eMMC
NVMeQSPI + SSD nvme0n1 на GEACX1
ОбаДва прохода; между ними новый Recovery

Rootfs/BSP уже в частях архива. Интернет нужен для APT. Подготовка образа на ПК ещё не прошивает плату.

Если SSD нет — выбирайте eMMC. Для NVMe нужно ≥64 ГиБ (68,7 GB), практически 128 ГБ+.
NVMe-рецепт основан на vendor-файлах, но физически на вашей плате здесь не проверен. При двух ОС носитель может потребоваться выбрать в UEFI.

5. Войти в Force Recovery

Подключите питание и U2 к ПК. Только один Jetson.
Зажмите RECV.
Удерживая RECV, нажмите RST на 1–3 с. Отпустите RST, затем RECV.
Чёрный экран нормален. Ожидаемый USB ID: 0955:7023.

Recovery повторяется перед каждым проходом.

6. Записать и проверить

Точная фраза для eMMC:

ERASE GEACX1 32GB

Для NVMe:

ERASE NVME GEACX1 32GB
Выбранный накопитель будет стёрт. Enter без текста отменяет запись.
  • Не отключайте питание/USB, не усыпляйте ПК.
  • После успеха: Reset без RECV, HDMI, первый запуск Ubuntu.
  • На плате выполните bash POSTCHECK.sh.
  • Проверьте HDMI, Ethernet, USB и нужную периферию.
CUDA, cuDNN, TensorRT и полный nvidia-jetpack не входят в базовый образ. Установите их после загрузки с проверкой совместимости JetPack 7.2 / R39.2.0.

7. Копия и ошибки

Меню 7: backup/restore через Recovery. Фразы: BACKUP GEACX1 и RESTORE GEACX1 BACKUP. Сохраните всю папку копии.

Не входят: EEPROM, eFuse, CPLD, eMMC boot0/boot1/RPMB.

Если ошибка

  • USB: мастер показывает скорость соединения, проверяет отсутствие переподключений 3 секунды и временно отключает автосон USB. 480 Мбит/с — не скорость записи и не гарантия качества кабеля. При обрывах смените кабель/порт, уберите хаб.
  • Ожидание появления USB-сети initrd увеличено с 60 до 300 проверок. Ctrl+C запрашивает STOP без блокировки журнала. Автоматического повтора записи нет.
  • Автосон USB не блокирует сон ноутбука. Подключите зарядку, оставьте крышку открытой. Лимит 2 часа относится только к скачиванию rootfs.
  • Место/ext4: после распаковки комплекта должно оставаться ≥80 ГиБ.
  • Контрольная сумма: заново скачайте весь ZIP проекта через Code → Download ZIP.
  • Нет загрузки: Reset без RECV, UEFI, HDMI, полный лог.

Журналы мастера: ~/geacx1-kit-v1.4/geacx1-recovery/logs/. Проверка распаковки: ~/geacx1-kit-v1.4/unpack-verification.log.

8. Материалы производителя

Комплект v1.4 использует NVIDIA Sample Root Filesystem R39.2.0 вместе с BSP, board, kernel и сервисами производителя для GEACX1 / 510JX0 r3.0.

Заводской rootfs v1.01 (16,67 ГБ) найден отдельно, но не скачан полностью: его MD5 и содержимое не проверены, поэтому он не включён.

Заводская система может иметь ту же основу и дополнительные программы/настройки. Содержимое не сравнивалось; разный размер архивов не доказывает различия файловых систем.

Не подменять компоненты

  • GEACX1-JP7.2.json универсального установщика на 2 октября 2026 года отвечает HTTP 404.
  • JP4/JP5/JP6, NX, GEACX1SC и другие ревизии не подходят вместо JP7.2.
  • MCU-архив оказался тестом GPIO/SPI, а не прошивкой.
  • CPLD автоматически не прошивается; совместимость старых v1.1/v1.3 и локального rb v1.4 не доказана.
  • Справка производителя: меню 5 → 4. Загрузка NVIDIA rootfs показывает скорость/ETA и останавливается при прогнозе более двух часов.

Дополнительные файлы в ~/geacx1-kit-v1.4/manufacturer-extra/ сохранены для справки и автоматически не устанавливаются. Подробности: docs/SITE_REVIEW_RU.txt.

Восстановление записывает QSPI и выбранный накопитель; CPLD, EEPROM, eFuse и Secure Boot ключи не сбрасываются.

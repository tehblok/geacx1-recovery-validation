# Дополнительная проверка GEACX1 Recovery v1.2

Этот приватный тестовый репозиторий содержит точные копии исполняемого кода
и тестов из готового архива v1.2, а также небольшую часть инструментов NVIDIA,
необходимую для проверки. Это не комплект для прошивки.

GitHub Actions запускает чистый контейнер Ubuntu 24.04 на настоящем x86_64
runner. Проверяются SHA-256 исходных файлов, 68 тестов Python, синтаксис
лаунчеров, реальная установка зависимостей исходным скриптом NVIDIA и нашей
обёрткой, запуск восьми утилит NVIDIA в режиме справки и аварийные сценарии
резервного копирования с подставными устройствами.

В аварийных shell-тестах используются обычные временные файлы: проверки
`-b`/`-c` заменены на `-e` только в тестовых копиях скриптов. Это проверяет
ветвление и передачу ошибок, но не распознавание настоящих block/char devices.
Перечень разделов также задаётся тестом; обнаружение физического накопителя
здесь не проверяется.

Запуск: Actions → Validate GEACX1 → Run workflow. Журналы сохраняются
в artifact `geacx1-ubuntu24-evidence`, в том числе при ошибке.

Здесь не проверяются физическая прошивка через USB, загрузка платы,
чтение/запись её накопителей или полная сборка образа системы. Контейнер
не получает USB, диски, Docker socket или privileged-доступ.

Готовый архив не меняется:
`GEACX1-JP7.2-Recovery-v1.2-Full.tar.gz`, SHA-256
`248b91f6165b3a24d05f9944f358dd8d4954aee3bd705b0ea78251c3ba3c7bb0`.

Файлы NVIDIA сохраняют исходные copyright/license notices;
лицензия находится рядом с ними в `recovery/vendor/…/Linux_for_Tegra/`.

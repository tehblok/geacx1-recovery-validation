3. CPLD

Инструкция CPLD прямо указывает для GEACX1 /dev/ttyTHS1. Описаны чтение версии,
чтение состояния, PPS lock, переключение источника времени, триггеры камер,
а также команды сброса и изменения режима. Последние не являются read-only
диагностикой; автоматически выполнять все команды этой инструкции нельзя.
Ссылка firmware для GEACX1 в этой инструкции ведёт на старый 510jx0-v1.1-e55.
В HTTP-каталоге найден 510jx0-v1.3; в локальной папке JP7.2 уже есть rb v1.4.
Версия v1.3 не является найденным обновлением нашего v1.4. Разные префиксы
tztek/rb и версии сами по себе не доказывают взаимозаменяемость образов.
Для GEACX1SC опубликован отдельный CPLD-пакет — не подменять им обычный GEACX1.
Новые материалы подтверждают функции синхронизации/камер; подтверждения,
что CPLD управляет стартом питания Orin на данной ревизии, не обнаружено.

4. УНИВЕРСАЛЬНЫЙ УСТАНОВЩИК НЕ ГОТОВ ДЛЯ JP7.2

SOP рекомендует tztek-jetson-tool-deb-install-v1.3.deb для сервисов/утилит,
но отдельно предупреждает, что ядро этот инструмент не обновляет.
Пакет скачан и разобран без установки/запуска.
Он определяет модель по /proc/dtb, версию JP по /proc/version и скачивает
внешний JSON. Отдельной проверки ревизии carrier r3.0 в коде не найдено.
http://221.224.80.18:2080/fae_use/GEACX1-JP7.2.json — HTTP 404.
В /fae_use/ имеются GEACX1-конфигурации до JP6.2 включительно.
В JP6.2 JSON указан CPLD v1.3, в JP6.1/JP5.1.1 — v1.2.
Следствие: не заменять набор JP7.2 старым списком пакетов и не включать
этот сетевой установщик как обязательный этап восстановления JP7.2.

5. MCU-АРХИВ ОКАЗАЛСЯ ТЕСТОМ

http://221.224.80.18:2080/packages/common/debs/geacx1-r3.0-jp5.1.1-mcu.tar.gz
Содержит test.sh и spidev_test: GPIO loopback и тест SPI. Прошивки MCU,

6. ПОЛЕЗНОЕ ДЛЯ НАШЕГО ВОССТАНОВЛЕНИЯ

- SOP требует ext4, сохранения прав и пути без китайских/специальных символов.
  В recovery уже есть проверка ext4 и безопасного ASCII-пути.
- SOP требует временно остановить udisks2, установить зависимости через
  l4t_flash_prerequisites.sh и обновить initrd. Эти этапы уже есть в мастере;
  состояние сервисов восстанавливается после операции.
- FAQ связывает проблемы NFS с доступом/межсетевым экраном. В мастере есть
  проверки IPv6/UFW и подсказки по USB-сети; глобально firewall не отключается.
- FAQ Q1/Q4: кабель с передачей данных, другой USB-порт, повторный Recovery.
  FAQ Q5: ASCII-путь и проверка целостности архива.
- Для переноса копии на другой накопитель SOP предупреждает о старых UUID
  в /etc/fstab. Это полезная диагностика после restore; не основание удалять
  все строки fstab автоматически. Восстановление повреждённой копии может
  вернуть исходную неисправную конфигурацию.
- Вложенный system-tar-and-restore-master-20251112.tar.gz указан как 85.83 KB
  и описан для backup из работающей системы. Это не замена recovery-копии
  QSPI и разделов не загружающейся платы.
- Указания Python 2 / Ubuntu 20.04 и таблица PCN-патчей JP5/JP6 относятся
  к другим поколениям. Не переносить их на R39.2.0 без проверки версии.
- В таблице есть отдельные GEACX1 32/64 GB, R2.1/R3.0, X1T и X1SC.
  Пример kernel-dtb-545t-1.3-nx-jp4.4-v2.4.6.deb из wget относится к GEAC90T /
  Xavier NX / JP4.4 и не подходит для GEACX1 / Orin / JP7.2.

8. БОЛЬШОЙ ЗАВОДСКОЙ ROOTFS

Для rootfs_jp7.2_ga-orin-release_v1.01.tar.gz сервер сообщил размер
16 671 921 264 bytes (16,67 GB / 15,53 GiB). Чтобы получить такой файл за два
часа, нужна средняя скорость примерно 2,32 MB/s. Полный файл не был получен:
его MD5 и содержимое не проверены, в recovery-комплект v1.3 он не добавлен.

Этот заводской rootfs нельзя считать тем же образом, что NVIDIA Sample Root
Filesystem R39.2.0 в комплекте. До отдельного скачивания, проверки MD5 и
сравнения состава неизвестно, содержит ли v1.01 дополнительные настройки.

9. ГРАНИЦЫ ПРОВЕРКИ

Из FAQ прочитана внешняя статья CSDN 2019 года о NFS/CentOS. Она не является
инструкцией для JetPack 7.2; советы об ослаблении firewall/exports в комплект
не переносились. NVIDIA PCN Center потребовал входа; таблица PCN в SOP
содержит старые JP5/JP6 и не доказывает необходимость патчей для R39.2.0.
SFTP-зеркало, указанное в SOP, в этом исследовании не проверялось.
Каталог просмотрен, но все 1292 файла не скачивались и не исполнялись.
Физическая прошивка и загрузка платы остаются непроверенными.

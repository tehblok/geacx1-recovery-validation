Дополнительные исходные пакеты производителя

Здесь сохранены три пакета из исходной папки производителя для полноты комплекта.
Мастер JetPack 7.2 НЕ устанавливает эти файлы.

- kernel-dtb ... jp6.0.0: пакет для другой версии JetPack; не устанавливать поверх JP7.2.
- kernel-dtb ... nx-jp4.4: пакет для другой платы/версии; не устанавливать на этот GEACX1 JP7.2.
- firmware-cpld ... sc-v1.2: отдельная прошивка CPLD; не входит в восстановление Jetson/QSPI.

Большой DEB сохранён частями для ограничений GitHub. Корневой START.sh автоматически
собирает исходные файлы в ~/geacx1-kit-v1.2/manufacturer-extra/ и проверяет SHA-256.
Ничего из этой папки не запускается и не устанавливается.
